# ispos/backoffice

Back office package for iSPOS — admin UI, auth, catalog, inventory, CRM, reports, and accounting.

## Contents

- Web routes (admin, dashboard, KDS, profile, auth)
- Inertia pages and shared UI components (`resources/js`)
- Styles (`resources/css`)
- Blade root view (`resources/views/app.blade.php`)
- HTTP controllers and form requests

## Integration

Registered automatically via Composer (`ispos/backoffice` path repository in the root app).

The host app provides domain services, models, policies, and API routes.
